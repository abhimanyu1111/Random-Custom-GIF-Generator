#Random GIF Generator

A simple React project built to practice and test my understanding of React concepts, API integration, and custom hooks.

#Features
Fetches random GIFs using the GIPHY API
Generate a new GIF with a button click
Search/fetch GIFs based on tags
Loading spinner while fetching data
Uses a custom useGif hook
Uses Axios for API requests

#Tech Stack
React.js
Axios
Tailwind CSS
GIPHY API
Purpose

This project was primarily built to test and strengthen my understanding of React, including:

useState
useEffect
Custom Hooks
Component-based architecture
API calls
Conditional rendering
Props and state management

Run Locally
git clone <your-repository-url>
cd <project-folder>
npm install
npm start

Create a .env file:

REACT_APP_GIPHY_API_KEY=your_giphy_api_key

Then start the development server:

npm start

Note

This is a learning project rather than a production application. The main goal was to practice React and understand how frontend applications interact with external APIs.
